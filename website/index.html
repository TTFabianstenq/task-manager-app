Task Manager

Android process list + End process. Not a to-do list.

Download from the GitHub release. Tap task-manager.apk under Assets. Wait for the new 2.0 build to finish first.

Open GitHub release Build status

What it does

  • Shows RAM used / free
  • Lists apps / processes Android will expose
  • End button calls killBackgroundProcesses
  • Needs Usage access in Settings for a useful list

Android will not let a normal app force-stop foreground apps. That needs root or a system app.

Task Manager

Clean, offline Android task manager

v1.0.0 · Kotlin + Compose

Download the App

This is a modern, offline-first task manager for Android. Built with Jetpack Compose, Room database, and Material 3.

  • Create, edit, complete & delete tasks
  • Priority levels (Low / Medium / High)
  • Search + filter (All / Active / Completed)
  • Works completely offline
  • Dark mode support
Download from GitHub Actions View Source
How to get the APK:
1. Go to the Actions tab of the repository.
2. Open the latest successful workflow run.
3. Download the app-debug artifact and unzip it.
4. Install the APK on your phone (enable "Install from unknown sources" if needed).

Note: The first time you open the project in Android Studio, it generates the Gradle wrapper. After you push the wrapper files, the CI will automatically produce downloadable APKs on every push.

Build it yourself

Prefer a signed release build or want to customize?

  1. Clone the repo
  2. Open in Android Studio (Ladybug or newer)
  3. Let Gradle sync
  4. Build → Generate Signed Bundle / APK
